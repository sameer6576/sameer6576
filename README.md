A hotel marketplace built with **Java 21, Spring Boot, PostgreSQL, React, and TypeScript**.

- Reserved vs. booked inventory management
- 10-minute booking holds

- Automatic refund handling for late payments
- Dynamic pricing based on occupancy, booking proximity, and configured holidays
